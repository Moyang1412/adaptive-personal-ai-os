**用自然语言提出目标，让 Agent 选择合适的工作方式。**

智序是一份可安装的 Agent Skill，用于学习、计划与决策、任务续接、生活支持、个人上下文复用和记忆方案选择。公共核心提供工作方法，使用者自己的配置决定协作偏好，私人文件或已选 provider 保存经过授权的背景与进度。

不是新模型，不是独立 App，也不是全自动人生管家。

## 可以怎样使用

| 场景 | 你可以这样说 | 预期作用 |
|---|---|---|
| 学习 | “我想系统学会分析数据。” | 结合目标与基础，安排练习和反馈。 |
| 生活支持 | “帮我安排家务，留出想休息的时间。” | 按本人目标处理日常习惯、健康生活、家庭收支、职业探索与关系支持。 |
| 决策 | “帮我比较这几种方案。” | 梳理约束、证据和取舍，提出建议。 |
| 任务续接 | “读取当前进度，继续下一步。” | 从真实状态继续，减少重复解释。 |
| 个性化协作 | “按我保存的协作偏好来处理。” | 在授权范围内复用相关配置与背景。 |
| 记忆方案 | “我需要跨会话记忆，先检查现有能力。” | 先用原生记忆；有明确缺口时再评估已安装 provider。 |

这些是工作流的设计目标，不是所有模型都能稳定做到的保证。1.0.0 是智序的首个正式版；正式发布不表示学习或生活效果已经得到科学验证。[查看使用示例 →](docs/EXAMPLES.md) · [1.0.0 发布与验证记录 →](docs/RELEASE-1.0.0.md)

## 开始使用

**Claude Desktop / Cowork 首选插件市场安装：**进入 `Customize → Plugins → Add marketplace → Add from a repository`，填写 `Moyang1412/adaptive-personal-ai-os`，再安装 `zhixu`。市场名为 `zhixu-skills`。实际菜单与可用性以客户端和组织策略为准。

也可从 [v1.0.1 Release](https://github.com/Moyang1412/adaptive-personal-ai-os/releases/tag/v1.0.1) 下载 `zhixu-1.0.1-plugin.zip` 上传。桌面端实际识别、启用和加载仍待实机验证。[插件安装与验证 →](docs/CLAUDE-PLUGIN.md) · [1.0.1 变更与边界 →](docs/RELEASE-1.0.1.md)

**同一宿主只保留一个活动入口：插件或直接 Skill。** Codex、DSH 和直接使用 Skill 的用户采用下面的方式。

已有 **Codex、Claude Code 或 DSH** 即可尝试；核心不需要额外服务器、API 密钥或 Python，也不会自动建立记忆数据库。

**把下面这段交给你自己的 Agent：**

```text
请安装智序 Skill：
https://github.com/Moyang1412/adaptive-personal-ai-os/tree/v1.0.1/skills/adaptive-personal-ai-os
先检查当前 Agent 的技能目录和已有同名版本。
不要覆盖个人配置、记忆或其他 Skill。
安装后报告实际路径，并用技能列表或加载记录核对是否生效。
```

这是交给有相应工具和权限的 Agent 的安装请求，不是保证每个平台都支持的一键命令。也可以下载仓库，手动复制整个 Skill 文件夹。

| Agent | 文档列出的用户级目录 | 显式调用 |
|---|---|---|
| Codex | `~/.agents/skills/` | `$adaptive-personal-ai-os` |
| Claude Code | `~/.claude/skills/` | `/adaptive-personal-ai-os` |
| DSH | `~/.agents/skills/` 或 DSH 配置的目录 | 从当前界面的 Skill 列表选择 |

**本版完成文件与文档层适配，三款 Agent 的实机行为仍待验收。** 自定义安装位置和组织策略可能不同。[完整安装与排错 →](docs/INSTALL.md)

安装后可以试：**“智序，帮我规划一项学习任务。”**

> 回答看起来正确，不代表 Skill 已经加载。先核对实际技能列表、文件路径或加载记录。

## 公共方法与个人配置分开

```text
公开 Skill：通用方法和流程
          ＋
你的私人档案：偏好、目标、学习进度、项目状态
          ＋
当前 Agent：它实际拥有的模型、工具和权限
```

**无需配置也能先用。** 需要长期连续性时，Agent 只在首次需要时检查已有原生记忆和用户已经安装、授权的 provider，再给出四个选择：

- **A 原生记忆**：原生能力覆盖需求时继续使用。
- **B 原生记忆 + 私人档案**：明确需要跨 Agent，且有范围和版本/锁保护时使用。
- **C 已安装的成熟 provider**：发现明确缺口，且安装、启用、可调用、许可证、维护状态和隔离测试都通过时使用。
- **D 暂不使用额外记忆**：没有缺口、没有权限、尚未验证或用户不想保存时使用。

安装 Skill 不等于安装 provider。没有合适 provider 时，优先选择 D；手工 Markdown 只是最小文件型备用记录，不是完整记忆引擎。已有背景优先复用，不扫描全部历史，不强迫重新介绍自己。

私人资料留在使用者指定的独立目录。个人偏好只影响本人，不会成为其他人的默认规则。换 Agent 时可以授权它读取同一份档案；换模型服务或账号时，需要重新明确共享范围。公共 Skill 升级不应覆盖个人资料。

**公共 Skill 只负责判断、路由、授权和边界；具体保存、读取、纠错、删除和导出交给已选 provider。** 不包含独立记忆数据库、向量检索、自动同步、原生历史导入器或代码级权限控制。[记忆方案与迁移 →](docs/PROVIDERS.md) · [如何保存、纠错、遗忘 →](docs/MEMORY.md)

## 学习流程与效果边界

1.0.0 纳入双模式学习。已安装副本不会自动更新；升级时核对实际加载路径并保留私人资料。

**明确目标 → 直接开始，或自选简短诊断 → 练习与反馈 → 独立新任务 → 延迟保持与迁移检查 → 调整路线**

默认从实际学习或任务开始，利用用户提供的表达和操作逐步了解基础。简短诊断可选、可跳过、可随时切换；不在每次开场强制选择模式。已有明确偏好继续有效。

两种方式使用同一标准：按具体能力、表现和所需帮助判断；依据证据减少已掌握部分的重复教学。助手完成不算用户掌握，拒答或回复慢不表示不会；证据不足就保留未知，并继续提供帮助。学习卡与长期保存均可选。

采用有研究依据的方法，不代表这份 Skill 已证明能提高学习成绩。科学性要用后续独立表现、保持与迁移核验；效率要比较同等学习效果下的时间和负担，不能只看问题少或完成快。不会保证最优路线。[学习协议与研究依据 →](skills/adaptive-personal-ai-os/references/learning.md)

## 其他工作方式

从已提供的信息开始，按需加载相应说明。只追问会改变下一步的缺口；简单请求直接处理，不要求先填问卷。

| 工作方式 | 本版方法 |
|---|---|
| 计划 | 核对现实容量与依赖，写清完成条件和可立即开始的一步；容量不足时缩小范围或调整安排。 |
| 决策 | 区分事实、估计和个人取舍，找出关键未知，并说明什么条件变化会改变建议。 |
| 研究 | 核对来源是否支持具体主张、适用于什么人或任务；已有足够依据时结束检索。 |
| 记忆 | 按授权范围、来源和事件时间查找；区分计划与实际结果，保留未解决的冲突。 |
| 续接 | 将交接记录与当前文件和完成证据对照，再执行下一步。 |
| 复盘 | 对照预期与实际结果，选择一个可检验的改变，避免把猜测的原因当成事实。 |
| 沟通 | 按所求先给草稿、倾听或梳理；不强迫披露背景，起草不等于发送。 |

记忆继续沿用现有原生能力及已授权 provider，不新增引擎或扩大读写范围。GitHub 实践与论文支持部分设计选择，不能证明本 Skill 的效果；还需比较实际结果、错误和交互负担。[来源核验与适用边界 →](docs/RESEARCH-NONLEARNING-2026-10-13.md) · [行为验证与未验证项 →](docs/VALIDATION-NONLEARNING.md)

上述合成验证绑定当时的候选文件快照。1.0.0 的发布检查单独记录，不能把旧快照结果当成当前宿主或真实用户验收。

## 生活支持

目标由本人决定。休息、享受爱好、照顾家人或让收支更稳，都可以是完整目标。从已有信息直接给有用的帮助，只追问会改变下一步的缺口；不强制测试、打卡、设备或人格标签，也不把休闲自动变成赚钱任务。

| 需要 | 可以提供的帮助 |
|---|---|
| 日常习惯、家务与休闲 | 调整环境与任务大小，安排可行的一步，保留想要的休息与乐趣。 |
| 健康生活 | 按现有条件讨论睡眠、饮食与活动习惯；症状或诊疗需要单独处理，不给个人诊断或处方。 |
| 家庭现金流与消费 | 核对金额、到账和付款时间、必要支出，再比较购买或延后；不套固定预算比例。 |
| 职业探索 | 对照实际约束与岗位信息，设计成本可承受的了解或尝试，由本人决定是否继续。 |
| 关系与情绪支持 | 按所求倾听、梳理或起草沟通；不猜测他人动机，也不要求把感受变成练习。 |

按需读取[生活支持入口](skills/adaptive-personal-ai-os/references/life.md)，不叠加整套问卷。涉及具体医疗、财务或法律判断时，核对当前可靠来源与当地条件。敏感资料读写、跨服务共享和外部联系沿用现有授权；请求建议不自动授权读账户、保存私事、发消息或购买。

研究为部分方法提供依据，不能证明本 Skill 改善健康、财务、关系或生活质量。生活候选四组单次匿名对照均持平，未证明总体更高效。[生活领域来源核验 →](docs/RESEARCH-LIFE-2026-10-13.md) · [候选验证范围与未验证项 →](docs/VALIDATION-LIFE.md) · [1.0.0 发布记录 →](docs/RELEASE-1.0.0.md)
