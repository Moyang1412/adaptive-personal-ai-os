# 你的记忆，留在你自己的地方

[返回首页](../README.md) · [English protocol](../skills/adaptive-personal-ai-os/references/memory.md)

## 先使用，再按需个性化

下载智序不会自动建立档案，也不会扫描你的历史。它先使用当前会话中已有且相关的背景。需要长期连续性时，你再决定是否保存，以及保存到哪里。

**不保存：**这次不读取、不写入智序的持久档案。

**确认后保存：**先知道将记住什么、关于谁、适用范围和保存位置。

**授权低敏积累：**在约定范围内保留低敏偏好与进度；敏感信息和重要更正另行明确。

这些只是智序的协作规则，不能代替宿主原生记忆或聊天历史设置。

## 最小私人档案

用户可以选择一个不属于公开仓库、也不在 Skill 安装包里的独立目录，例如 `~/ZhiXu-Private/`。只在用户要求时创建，位置要让获准使用的 Agent 明确知道，不全盘搜索。

最开始只需要 `PROFILE.md`（偏好、目标与授权范围）和 `MEMORY.md`（少量已确认记录）；学习和项目状态优先沿用现有文件。无需一上来建立十几份模板。

每条重要记忆保留：**内容、关于谁、来源、日期、适用范围、确认状态、可共享服务与复查日期**。朋友的经历不应被记成你的，今天的情绪也不应变成人格标签。

## 查看、纠错、遗忘

你可以直接说：“你保存了什么？”“这不是我的经历。”“忘掉这一条。”

Agent 应先定位授权范围内的实际文件，用宿主工具读取或修改，并报告结果。没有写权限时只能提供草稿，不能说“已经记住”。不要静默覆盖另一位协作者刚写的内容。

删除当前文件中的记录，不代表旧对话、原生记忆、备份或已经进入模型上下文的内容都被删除。不得为了留痕又复制一份被要求删除的私人内容。

## 换 Agent，不等于把隐私重新公开

同一个人可以授权 Codex、Claude Code 或 DSH 读取同一份精选档案。但 **Agent 名称和模型服务商不是一回事**：更换服务或账号前，要明确哪些记录可以共享。

已有原生记忆不批量迁移。只读取当前已提供的相关背景，或用户指定的具体来源；先给候选摘要，再按授权写入，不覆盖原生文件。跨设备同步不由智序自动提供。

## 当前边界

本版依靠宿主的文件工具与人工授权，没有独立记忆引擎、加密、自动权限过滤、并发锁或数据库。多 Agent 共用档案时，采用单写入者，或使用宿主已验证的版本冲突控制。

本地保存也不意味着数据永不离开设备：供云端模型阅读的内容可能进入对应服务商的上下文。不要保存密码、密钥、验证码，健康、关系、财务信息默认不长期保存。

**公开 Skill 负责方法；私人档案负责你的事实。两者不能混在一起。**
