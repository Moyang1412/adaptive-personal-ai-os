## 可复用，但未安装的项目

先看现有环境和实际缺口；“继续原生能力，不加依赖”是有效选择。

| 对象 | 何时值得继续评估 | 这次没有做什么 |
|---|---|---|
| [MCP Memory](MCP-MEMORY-REVIEW.md) | 已有MCP宿主，需要小型图谱记录 | 未把文件路径、关系过滤当成完整隔离，也未安装 |
| [Mem0](MEM0-REVIEW.md) | 确实需要事实提取和语义检索 | 未启用模型/embedding调用；未默认授权推断式更新、删除 |
| [LangMem](LANGMEM-REVIEW.md) | 已在使用LangGraph/store | 未把namespace字符串当成身份校验或持久性证明 |
| [Letta / MemGPT](LETTA-REVIEW.md) | 已有或明确选择有状态Letta体系 | 未把历史V1教程当当前MemFS合同，未当作任意宿主即插即用记忆库 |
| [FSRS](FSRS-REVIEW.md) | 明确要做卡片复习排程 | 未把排程当提醒服务、跨Agent记忆或课程掌握度 |
| [教学Skill](TUTOR-SKILL-REVIEW.md) | 确实缺少合适的教学组织方式 | 只借鉴适用机制，没有强制整套问答或新增第二套学习数据库 |

具体版本、许可证、读过的文件、访问受限处和未核验项都在各报告中。
开源、论文发表或现有测试通过，都不自动满足安装、数据共享或付费授权。

## 怎样看验证记录

- 文件、格式、算术及模拟状态机检查：只支持对应实现和格式结论。
- 真实宿主行为：需要实际加载、工具轨迹、匹配条件和保留失败的比较。
- 用户结果：需要相应的独立表现或生活结果证据，不能由前两项直接推出。

当前数字和快照只维护在[验证状态](VALIDATION.md)，避免在多个页面重复更新计数。
较早的[非教学调研](RESEARCH-NONLEARNING-2026-10-13.md)与[生活领域调研](RESEARCH-LIFE-2026-10-13.md)保留当时日期和候选状态，不把它们改写成今天的新实验。
