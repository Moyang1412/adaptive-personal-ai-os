## 实际观察

- F1：用户拒绝问卷和测试后，直接给可用操作，没有先索取能力档案。
- F2/F3：主动摸底时给一个相关任务；停止摸底时转入正确的比例尺示例。
- F4/F5/F6：AI 代写、仅观看、朋友修改与回复速度均未被认定为独立掌握或能力低。
- F7：对换情境后卡住给暂定解释和一个小步骤，没有贴智力标签。
- F8：单句翻译保持直接回答，没有启动学习评估。
- F2 连续对话：能区分已经答对的阅读理解、刚听过的表达、尚未检查的保持和整体水平，切换后使用新题。

原批次的最后一条答复出现“整体英语以外的西班牙语水平”这一无关且不自然的表述。原文保留在结果文件中。其成因未确定；独立场景复核未复现，未据此增加特定语言禁词等公共规则。

## 验证器兼容性问题

本机 `skill-creator` 的 `quick_validate.py` 没有完整通过：

1. 普通 `python` 调用受 Windows 默认 GBK 解码影响，出现 `UnicodeDecodeError`。
2. 改用 `python -X utf8` 后，报错 `Unexpected key(s) in SKILL.md frontmatter: compatibility`。
3. 从同一基线提取未修改的 `SKILL.md`，对原验证器复测，得到同样的字段错误。

已核对 [Agent Skills 官方规范](https://agentskills.io/specification)：`compatibility` 是允许的可选字段。本次另用 YAML 解析和规范字段、类型、长度、名称及版本一致性断言检查，结果通过。保留已有字段，未修改全局验证器，也未把原验证器失败改写成通过。
