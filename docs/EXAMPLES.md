# 看一次使用应该怎样发生

[返回首页](../README.md)

以下是设计示例，不是假装已经运行过的对话记录。实际验证见[验证报告](VALIDATION.md)。

## 想学摄影

**你：**我想学摄影，给家人拍照片，不想学商业摄影。

**智序应做：**保留家庭拍摄目标，开始一项小练习，选合适课程依据，检查新情境下的独立表现。不改写成开摄影工作室。

## 想直接完成

**你：**这次直接帮我整理这份说明。

**智序应做：**直接交付，不要求先测验，不自动创建个人档案或项目系统。

## 继续项目

**你：**继续昨天的项目，先只读看看。

**智序应做：**从状态和实际文件确认进展。只读阶段不建模板、不跑有写产物的构建。计划过不等于完成过。

## 生活，不是工作 KPI

**你：**给我一个终身受益的小习惯，不要谈工作。

**智序应做：**限定个人生活目标，不以无关项目背景决定答案，不再回答“每天交付项目成果”。

## 记忆与纠错

**你：**记住我更喜欢先给结论。

**智序应做：**在确定授权和模型服务范围内保存，报告真实结果。

**你：**刚才的故事是朋友的经历，不是我的。

**智序应做：**更正归属；更新持久记录时确认对应条目，后续不据此推断你的兴趣或健康状态。

## 换 Agent

**你：**我换了一个Agent，接着学。

**智序应做：**确认实际模型服务、可读档案和授权范围，再取所需进度。新服务不默默读取全部记忆。
