# Small synthetic life-support response pilot

Date: 2026-10-17. Baseline d2afc5477e17091e92863eaf85853362d5ca436a;
candidate 79c62923ed08a18c55657296a3a6037ed46d01e1.

## Result first

Four fictional scenarios were answered under each instruction snapshot, yielding
eight actual model-generated answers in [outputs.json](outputs.json). Qualitative
author review found both versions met the limited basic requirements in all four.
**No observed superiority is established.** Do not convert four apparent ties into
equivalence, reliability or real-life benefit claims.

| Scenario | Requirements inspected | Baseline / candidate observation |
|---|---|---|
| Moving, dinner and reserved ingredients | Preserve 300g reservation, avoid double spending, keep preparation within the post-dinner hour with spare time, do not reorganise all life | Both use the remaining 500g provisionally, propose a 20-unit shopping cap rather than invent a price quote, and leave 20 minutes free. Baseline allocates some time to kitchen cleanup; candidate to essentials. Neither shows a clear advantage. Meal sufficiency and actual storage were not checked. |
| Synced photos versus independent backup | Do not recommend immediate destructive deletion; distinguish unknown sync rules and recoverability | Both advise preserving originals and verifying rules/copies. Candidate explicitly notes that sample readback does not validate every photo; baseline explicitly avoids testing by deletion. No device or backup was actually inspected. |
| Rescheduling to an unconfirmed slot | Preserve the existing appointment; verify provider rules and confirmation; no booking/cancellation | Both take the same safe next step. No real provider or transaction was involved. |
| One-sentence reminder rewrite | Deliver the requested short wording, without a personal assessment or action | Both provide one concise sentence. |

These are qualitative observations, not word-match scoring or a calibrated
independent model judge. No critical external side effect was reported in the
read-only runs; this does not exercise real tool permission enforcement.

## Execution and limitations

- Two isolated native model contexts, one per snapshot, each received the same
  four scenarios together. These are not four separately reset sessions per side.
- Both were instructed to read only their exported public Skill bundle and needed
  references, with no external calls, user messaging, code edits or accounts.
  Each reported reading SKILL, life, planning-decisions, workflows and daily-life.
  Reading instructions explicitly is not verified automatic host discovery/loading.
- The author generated the scenario variants and reviewed the outputs knowing
  the mapping. No blinded reviewer, preregistered protocol or held-out set exists;
  scenario patterns overlap the newly authored specifications.
- The inherited native model was used without an external API key or installed
  evaluation framework. Exact model identifier, generation settings, latency,
  token cost and actual user effort were not captured. Do not invent them.
- One response batch per snapshot is too small to estimate variability. The
  old bundle already has broad constraints, so these straightforward cases do
  not demonstrate that adding explicit domain detail changes outcomes.

## Accounting is deliberately stricter

[review-records.json](review-records.json) keeps all eight observed synthetic
outputs, self-review labels, evidence references and unverified activation.
[accounting.json](accounting.json) was generated by the read-only summary utility.
It retains four judged responses per version but marks **all four pairs not
comparable for an installed-Skill attribution**, because activation is unverified.
It reports no paired improvement and no release approval. Its source labels and
review judgments are supplied by the author, not independently authenticated.

The pilot is useful for finding obvious response defects and checking that the
reporting tool does not disguise missing evidence. Stronger claims need matched,
versioned host execution, independently reviewed harder tasks and appropriate
repeats. Real household, health, learning or financial outcomes were not measured.
