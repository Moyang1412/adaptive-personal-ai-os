# Routing cases

These examples are lightweight manual checks for the public Skill.

## Should trigger the personal AI OS

- “我有三个项目和一个学习目标，帮我按时间、精力和收益排优先级。”
- “新项目：先接手这个仓库，建立项目地图，不要修改代码。”
- “我想真正学会做产品，先测试我现在的水平。”
- “把这次失败复盘一下，判断哪些经验适合写进项目规则。”

## Should usually defer to a more specific Skill

- “把这张图片裁成正方形。”
- “把这个 PDF 转成表格。”
- “翻译这一句话。”
- “修复这个函数的类型错误。”

If the user explicitly asks to use the personal AI OS, it may still coordinate the task while delegating the specialized operation.
